# 早点下班 0.2.0-alpha.1

- `Getoff-Work-Early-0.2.0-alpha.1-x64-setup.exe`：Windows x64 当前用户安装包。
- `Getoff-Work-Early-0.2.0-alpha.1-x64.exe`：直接运行版；数据仍保存在当前用户应用数据目录。
- `SHA256SUMS.txt`：发布文件完整性校验值。

需要 Windows x64 和 WebView2。安装包未签名，Windows 可能显示未知发布者。

默认快捷键为 `Ctrl+Shift+Space`。关闭主窗口后会驻留托盘；需要完全退出时，使用设置页或托盘菜单。

数据目录：`%APPDATA%/com.zaodianxiaban.app/data/`。卸载默认保留数据。跨电脑请使用设置页创建密码加密 `.eowbak` 备份，不要只复制数据库。应用锁密码无法由开发者找回。

详见 `docs/阶段2验收记录.md`。
