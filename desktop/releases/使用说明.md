# 早点下班 0.1.0-alpha.1

- `早点下班-0.1.0-alpha.1-x64-setup.exe`：Windows x64 当前用户安装包。
- `早点下班-0.1.0-alpha.1-x64.exe`：直接运行版，不需要安装；数据仍保存在当前用户应用数据目录。
- `SHA256SUMS.txt`：最终文件 SHA-256 校验值。

需要 Windows 和 WebView2。安装包在缺少 WebView2 时需要联网下载安装运行环境。当前是未签名内测小样。

打开后可测试悬浮窗、托盘、快捷输入及加密收集箱；默认快捷键 `Ctrl+Shift+Space`。关闭主窗口会隐藏到托盘，真正退出请使用主面板或托盘的退出操作。

数据目录：`%APPDATA%/com.zaodianxiaban.app/data/`。卸载保留本地数据。请勿单独删除账户密钥文件。

当前保留一条「技术小样验收」事项用于展示跨窗口保存；没有替用户进行上下班打卡。

详见上级目录 `README.md`、`CHANGELOG.md` 与 `docs/阶段1验收记录.md`。多屏缩放、各办公软件兼容、初装覆盖升级等仍需专项验证。
