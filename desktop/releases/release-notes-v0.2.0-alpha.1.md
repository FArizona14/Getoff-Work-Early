阶段 2「本地可用闭环」开发版。

## 本版新增

- 今日、未来、收集箱、已完成任务视图，支持全部基础管理操作和完成成果。
- 常见中文日期识别与保存前调整，未来任务不再混入今日。
- 工时补录 / 修正、审计痕迹、可配置展示卡点。
- 月薪 / 年薪估算、收入进度、加班实时时薪、隐私模式与趣味彩蛋。
- Argon2id 应用锁、本机滚动备份、SHA-256 校验和密码加密便携备份恢复。
- 旧版收集箱数据自动迁入新任务收集箱。
