## 早点下班 0.1.0-alpha.1

这是首个 Windows x64 桌面技术小样，用于验证 Tauri 桌面能力、本地计时、快捷收集和加密存储链路。

### 本版包含

- 主面板、置顶悬浮窗和快捷输入卡三个独立窗口。
- 系统托盘、关闭到托盘、单实例和开机启动设置。
- 悬浮窗拖动、边缘吸附、位置恢复及可见工作区校正。
- 上班、满九小时自动进入加班、下班锁定、跨午夜归属和重启恢复。
- 默认 `Ctrl+Shift+Space` 主动采集选中文字，快捷键可修改。
- SQLite 版本迁移、迁移前备份，以及 AES-256-GCM + Windows DPAPI 的本地字段加密。
- 当前用户安装的 Windows x64 NSIS 安装包和免安装运行版。

### 已验证

- TypeScript 严格检查和 Vite 发布构建通过。
- 4 项 Rust 测试通过：计时状态机、跨午夜/重启恢复、SQLite 迁移及加密/DPAPI。
- 三窗口启动、快捷输入保存、跨窗口同步、主面板关闭后托盘常驻、单实例和全局快捷键唤起通过。
- npm 锁定依赖漏洞检查未发现已知漏洞。

### 使用说明

- 推荐下载 `Getoff-Work-Early-0.1.0-alpha.1-x64-setup.exe`。
- 安装包尚未签名，Windows 可能显示“未知发布者”或 SmartScreen 提示。
- 首次运行数据保存在 `%APPDATA%/com.zaodianxiaban.app/data/`，卸载默认保留数据。
- 当前剪贴板含图片、文件或富文本时，应用会跳过自动复制并提示手动粘贴。

### 当前限制

这是技术验证版本，不建议存放唯一一份正式工作资料。完整任务管理、报告、应用锁、隐私模式、便携备份、云同步、自动更新尚未实现。Office/WPS/微信等软件兼容、多屏缩放和安装升级流程仍待专项测试。

文件完整性请使用随附的 `SHA256SUMS.txt` 核对。
