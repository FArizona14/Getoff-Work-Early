# 早点下班 · 首版原型 V0.1

确认日期：2026-11-05  
对应需求文档：工作区根目录 `PRD-早点下班办公助手.md`（V0.3）  
视觉依据：工作区根目录 `UI视觉风格分析与设计规范.md`

## 打开方式

双击本目录下的 `index.html`，用 Edge 或 Chrome 打开。`early-off-work-prototype.html` 是可继续修改的原型源文件；`index.html` 为浏览器预览版。

图标等预览资源可能需要联网加载。此文件是交互原型，尚未打包为 Windows 桌面应用。

## 本次确认的设计

- 浅蓝—薰衣草紫—淡粉渐变主视觉、抽象流体形状、窄侧栏、轻玻璃指标卡。
- 今日、未来、已完成、工作回顾、绩效素材和设置页面。
- 悬浮窗时长置于进度条右上角，以 `06:08:00 / 9h` 紧凑显示。
- 进度条使用带渐隐拖尾的动态流光；下班后停止，系统减少动态效果时关闭。
- 上班计时连续增长，满九小时自动进入加班中。
- 九小时内收入增长；九小时后隐藏收入进度，改为“今日每小时牛马费低至”。
- 加班时薪按当日封顶薪资 ÷ 累计在岗小时数计算，每秒重算；下班后固定最终值。
- 同一天已下班后不能重新上班，恢复状态后仍锁定。
- 支持划词添加入口演示、常见日期表达预览和手动调整日期。
- 周报包含重点工作、成果与指标、问题风险、个人学习、下周计划五部分。

## 体验提示

- 首次打开会显示悬浮窗，可以关闭后查看主面板，也可以通过右上角按钮重新打开。
- “演示：快进至 9h”用于快速观察自动进入加班状态；正式产品不会提供该按钮。
- 点击“下班打卡”会冻结当天计时，请在需要观察流光和时薪变化后再点击。
- 在设置中切换金额可见性和窝囊费彩蛋。

## 原型范围与开发边界

这版用于确认视觉和主要交互。列表、报告、年度成果、薪资样例使用演示数据；本轮确认不表示相关业务已经开发完成。

已实现的原型行为包括页面切换、部分待办添加、日期调整、连续计时、九小时状态切换、加班时薪变化、隐私遮挡和下班状态锁定。

以下仍待正式开发：

- 真正的桌面置顶悬浮窗、系统托盘、开机启动与多显示器适配。
- 系统全局快捷键、跨应用划词和剪贴板恢复。
- 完整的任务数据库、工作日历、薪资设置计算和数据备份。
- 周五自动生成周报、AI 整理、真实复制导出与年度自评生成。
- 完整的日切、跨午夜会话、休眠重启恢复和异常修正。

原型中的“复制周报”“生成自评”等部分按钮仅展示反馈；任务和报告编辑尚不具备完整的持久化能力。不要把原型作为正式工作记录工具。

## 已完成的验证

浏览器验证通过：

1. 时长位于进度条右上角，字体为 12px。
2. 流光动画存在，已下班后关闭。
3. 连续计时跨过九小时边界自动进入加班中。
4. 加班一小时后时薪从约 ¥62.22 降至约 ¥56.00（日薪样例 ¥560）。
5. 隐私设置同时遮挡收入金额与加班时薪。
6. 下班后时间、时薪冻结，旧状态同步不能重新开启当天计时。
7. 从已保存状态恢复后仍保持已下班锁定。
8. 日期手动调整、五段周报和主要导航可用。
9. 320 / 390 / 736 / 1024px 宽度下主要页面无水平溢出。

上述为浏览器原型验证，Windows 系统层面的能力还需下一阶段验证。
